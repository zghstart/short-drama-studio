# 后期与验收

## 真实素材与时间线

用 ffprobe 读取实际时长、画幅、帧率和音轨。生成请求里的10秒不等于实测10秒，导出1080p不等于模型原生1080p。

更新 `film.json` 中选定素材的入点、取用时长和实际对白。按精确帧数控制长度，不悄悄重复镜尾或拉长音频掩盖素材不足。小于一个源帧的舍入差可补齐，实质性缺帧应重新剪辑或说明。

剧情可使用硬切、动作匹配与声音跨切。转场为叙事服务，不要求每镜淡入淡出。复杂转场可用当前可用的 NLE、Remotion、HyperFrames 等工具；随附渲染器负责顺序拼接。

## 字幕与标题

按实际说话时间对齐。ASR可核对漏字、错词和完整性，不能证明声线一致、说话人正确或口型同步。

按画幅和播放尺寸选择字体、描边、行宽与安全区。中文使用支持中文的字体，先渲染实际字符再批量导出。标题、角色标识和界面不要挡眼睛或关键道具。

FFmpeg缺少 `drawtext` 或 `subtitles` 时，可用Pillow渲染透明PNG再合成。随附渲染器显式写入每一帧，字幕层与主片帧率和帧数相同。稀疏图片列表声明的时长，不保证最后一条字幕显示到片尾。

检查第一句、揭晓处、跨镜头处和最后一句。字体存在、SRT正确、视频可解码，都不能代替查看实际烧录画面。

## 声音

区分同期声、画外音、配音、环境、音效与音乐。统一对白响度，避免接缝爆音、音乐重启和背景压住对白。静音应是有意选择；无音轨不能写成已配音。

照片没有声线。原生视频可能带对白，跨请求仍需听辨；需要时选统一配音或已确认声音参考，并核实模型确实支持相应输入或口型流程。

只改字幕或画面时，解码后的音频哈希完全一致，可以复用已有转写证据；音频变化后按范围重新核对。

## 成片检查

1. 整个文件完整解码。
2. 实际时长、帧数、画幅与音轨匹配目标。
3. 对白可听清，字幕对应实际声音，包括最后一句。
4. 开始、中段、结束和接缝的人物、衣服、光向、道具与姿态合理连续。
5. 说话人与嘴型相符，画外对白没有让错误人物开口。
6. 故事在当前范围内完整，片尾没有截掉结果或尾句。

`inspect_media.py` 验证技术属性，`--decode` 完整解码，`--frames-dir` 抽帧供查看。程序通过不等于故事、表演或相似度已通过。

按用户要求交付成片，只有修改、复用或审阅需要时再附工程与中间文件。
