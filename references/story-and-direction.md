# 故事与导演

## 开发故事

简报记录交付阶段、类型、受众、目标时长、画幅、语言、可用人物与参考、制作资源。用户已有的选择优先；没有预算数字不等于必须追问一个数字，先根据服务价格和任务规模判断是否有实质性费用不确定性。

从一句话开始：谁在什么处境中，为了什么做了什么，因此遇到什么变化，最后得到怎样的结果。把背景设定与观众在片中实际知道的信息分开。

30秒左右通常一个即时冲突、一个改变局面的行动和一个落点就已足够。两分钟可以有数次升级和更充分的铺垫。这是容量判断，不是固定分段公式。悬疑、喜剧、情感与爽剧的反应停顿和信息节奏不同。

反查转折：揭晓依赖的身份、道具、空间或规则，是否在此前存在？主角是否采取了改变结果的行动？如果只是突然出现救场人物，考虑让此前的主角选择促成其出现。

连续剧维护每集结束后的关系、人物知识、物品、地点与悬念状态。本集可以留悬念，但不要用片尾字样遮掉本应出现的回报。

## 剧本与对白

每场写内外、时间、地点、出场人物、可见行动、对白与声音。行动也占时间。以自然朗读估算台词长度，再为反应和剪辑留空间；生成后以实际音频重排。语速估计不能证明已经对上口型。

分别标注当面对白、电话等画外声音、主观旁白和只供观众阅读的文字。每句话应改变信息、关系、行动或情绪。反复表达同一个意思的句子可删；用可见反应承接话语，不把全片都写成正脸讲述。

## 导演说明

确定摄影质感、光源方向、色温、轴线、人物站位、表演强度、运镜、声音空间及转场逻辑。用明确取景和机位关系约束画面，不靠堆叠摄影术语增加质量。

先用位置锚点描述空间，例如两人隔桌相对、窗户在摄影机左侧、门在后方，再转换为该机位的前后景、左右与视线。摄影机位于某人肩后时，通常看到对面人物的正面；要拍其背面，需重新确认机位，不能同时要求相反的观察关系。

换姿态、换手、拿起/放下道具及进出场时，要有合理承接。选择省略过程时，下一镜状态也须能被理解。反射、多人交接、精确接触或大运动需要更清楚的起止状态。

## 分镜卡

| 字段 | 内容 |
| --- | --- |
| 镜头与场景 ID | 追溯剧本和素材 |
| 叙事职责 | 观众在这一镜得到什么 |
| 时长 | 成片取用时间；另记生成请求时长 |
| 取景与机位 | 景别、朝向、视线、人物位置和运动 |
| 起止状态 | 人物姿态、道具位置、进入与退出状态 |
| 行动与表演 | 主要动作、情绪变化、停顿 |
| 声音 | 说话人、对白、画外音、音效和音乐意图 |
| 参考与后期 | 实际输入图的职责、精确文字和合成位置 |
| 承接 | 与下一镜依靠什么动作、视线、信息或声音关系衔接 |

生成请求与剪辑镜头不必一一对应。较长片段可以剪出几个反应镜头；一个生成段也可以包含模型稳定支持的内部切镜。根据可控性、动作复杂度和实际模型能力安排，不统一强制十秒或两秒。
